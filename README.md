Predicting the severity of Parkinson's Disease symptoms using 
Machine Learning on biomedical voice measurements.

---

## 📌 About

Parkinson's Disease is a neurological disorder where early monitoring 
of symptom severity is critical for treatment. This project uses 
voice-based features to predict the UPDRS score — a standard clinical 
measure of Parkinson's severity — without any hardware or sensors.

Inspired by **CortiCare** — Smart India Hackathon 2025 (Problem ID: SH25218)

---

## 📊 Dataset

Oxford Parkinson's Disease Telemonitoring Dataset (UCI)

- 5,875 voice recordings from 42 patients
- 22 biomedical voice features (Jitter, Shimmer, HNR, RPDE, DFA, PPE)
- Target: motor_UPDRS and total_UPDRS severity scores
